# Harjoitus 5 - Gitar Hero

## x) lue ja tiivistä

- **1.3 Getting Started - What is Git?:**
Git tallentaa jokaisella `git commit` -komennolla ns. "valokuvan" koko projektin tilasta pelkkien tiedostomuutosten sijaan, mikä tekee versioiden vaihtamisesta nopeaa.
Koko versionhallintahistoria sijaitsee omalla koneellani .git-kansiossa, joten lokien selaus ja muutosten tekeminen onnistuu ilman verkkoyhteyttä.
Jokaisesta tiedostosta lasketaan yksilöllinen SHA-1-tarkistussumma, joten mikään ei voi muuttua Gitin huomaamatta.
Tiedosto etenevät tiloista Modifien -> Staged (`git add`) -> Committed (`git commit`).
Oma havainto: Staged-tila tuo mielenrauhaa, voi vapaasti muokata tiedostoja ja testata niitä, ennen kuin tehdyt muutokset lukitaan.

* **'git add --all && git commit; git pull && git push':**
* git add --all: Lisää kaikki uudet, muokatut ja poistetut tiedostot valmistelualueelle (staging area)
* &&: Tämä merkintä tekee sen, että seuraava komento suoritetaan vain jos edellinen komento onnistui
* git commit: Tallentaa staging arealle kerätyt muutokset pysyväksi tilanteeksi paikalliseen .git -tietokantaan.
* ; : Tämä taas erottaa komennot site, että jälkimmäinen osa ajetaan vaikka edeltävät komennot eivät olisi onnistuneet.
* git pull: Hakee etärepositiosta mahdolliset uudet muutokset ja päivittää ne omaan paikalliseen repooni.
* git push: Lähettää paikalliselle repolle tallentamani tiedot etärepoon GitHubille.

## b) Dolly

Tässä lähdin siitä liikkeelle, että asensin koneelleni git:n, sitä ei entuudestaan minulla ollut ja sitten opettajan vinkkien mukaisesti kopioin julkisen SSH-avaimeni GitHubiin, sama tehtiin myös Linux-palvelimet -kurssilla, jotta joka kerta ei tarvitse syöttää tunnuksia ja salasanoja.

<img width="1883" height="323" alt="image" src="https://github.com/user-attachments/assets/39aad41a-25dd-4c20-a855-de9e28614f4b" />

Tämän sai korjattua seuraavalla komennolla: `git remote set-url origin git@github.com:TommiKarell/tompan-sunshine-harjoitus5.git`.

## e) Gitanbile

Aluksi tuskailin tässä koska en jostain syystä tajunnut heti, että mitä tarkoitetaan "Laita versionhallintaan", yritin vain komennolla `git status` tarkistaa että toimiiko git tässä kansiossa, lueskelin nettisivua: https://docs.gitlab.com/topics/git/commands/ ja sieltä löysin tuon `git innit` -komennon, joka siis loi tähän tyhjän paikallisen Git-varaston. Tarkistin rakenteen ennen ja jälkeen.

<img width="1004" height="726" alt="image" src="https://github.com/user-attachments/assets/ac9a65c3-9941-4e65-957c-fffa7bd54ae5" />

Ja sitten kun syötti tuon `git status` -komennon niin näytti aika erilaiselta, se oli lisännyt kaikki Ansible-kansiossa olevat tuohon ymmärtääkseni Modified tilaan (eli vielä ei annettu `git add` -komentoa), sitten ajoin taas opettajan antaman `git add --all && git commit; git pull && git push` -komennon ja sitten vielä tarkistin loppuun että komento tosiaan toimi.

<img width="1004" height="719" alt="image" src="https://github.com/user-attachments/assets/0f44ac7d-558d-4c11-9c5f-40a7cf0b2087" />

Ja sitten halusin olla 100% että kansio on tosiaan lisätty versionhallintaan koska tämä on aika uutta niin loin taas uuden tiedoston, poistin sen, tarkistin että ei näy hakemistossa ja sitten tein komennolla `git reset --hard` taas sen tuhoamisen, näytti hyvältä ja sitten poistin sen oikeasti. En ottanut jokaisesta stepistä kuvakaappausta, mutta tarkistin lokin ja siellä tosiaan näkyy että se on onnistuneesti asennettu mutta myös onnistuneesti poistettu.

<img width="1004" height="835" alt="image" src="https://github.com/user-attachments/assets/590ff30b-de49-4dff-901e-e629d0806b20" />

Sitten oli aika tehdä joku muutos, menin niinkin pienellä ja yksinkertaisella että nano-komennolla avasin tuon `main.yml` -tiedoston ja muutin tekstiä, alunperin luki `See you at` niin nyt tulee `See meu at`, tuo U-kirjain jäi vahingossa mukaan, sitten tallensin muutoksen ja ajoin playbookin joka huomasi tämän muutoksen ja teki tarvittavat toimenpiteet, sitten tarkistin taas gitin tilan komennolla `git status` ja näytti selkeästi että tuota tiedostoa on muutettu, sitten taas opettajan antama komento `git add --all && git commit; git pull && git push`, tarkistus ja ainakin omaan silmään tämä meni oikein.
